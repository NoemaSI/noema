# Welcome to Noema

Noema is an interpretable white box machine learning library that builds explainable mathematical models of unknown or hidden mechanisms in data.

It uses Large Language Models (LLMs) to search and recover explainable models of real world processes and can be used as a python programming library or standalone program.
Use cases

- Find human error sources in business processes
- Troubleshoot industrial production lines
- Reduce the need for binding assays in molecule design
- Optimize and simulate sensor placements
- see examples

## Philosophy

Noema builds on top of state of the art Large Language Model inference techniques with the goal to be as hands free to it’s users as possible. It acts as a harness for modern Large Language Models and asks users for their input only when their domain knowledge is favorable to it’s integrated exploration and discovery capabilities.
